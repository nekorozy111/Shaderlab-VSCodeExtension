# My Extension

VS Code用の拡張機能です。

## Features

- コマンドを追加します
- VS Code上で便利な操作を提供します

## Usage

1. VS Codeに拡張機能をインストールします
2. `Ctrl + Shift + P` を開きます
3. `My Extension: Hello World` を実行します

## Requirements

特になし。

## Extension Settings

この拡張機能では設定項目を使用しません。
